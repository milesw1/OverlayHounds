# 1080p Hockey Broadcast Scorebug & Live Producer Studio (v2)

A static, zero-backend **1920×1080 live hockey broadcast scorebug, optional bottom broadcast ticker bar, sponsor rotator, and full-screen takeover studio** built for **GitHub Pages** and **Moblin's Browser Widget**.

## What's New in v2
- **Optional Full-Width Bottom Broadcast Bar + Ticker (`1920×54`)**: Switch between **Compact Corner Scorebug**, **Bottom Broadcast Bar + Scrolling Ticker** (ESPN BottomLine / SportCam style), **Bottom Ticker Only**, or **Hidden** with one click in the top bar or in **Setup & Layout**.
- **Customizable Bottom Ticker Crawl**: Add tournament schedules, sponsor shoutouts, and rink announcements that scroll smoothly across the bottom edge of your 1080p stream.

## Repository Structure
- `index.html` — Complete dual-mode broadcast studio (`Control Studio` + `?overlay=true` `1920×1080 Transparent Clean View`).
- `.nojekyll` — Prevents GitHub Pages from running Jekyll processing so static assets deploy immediately.
- `assets/` — Optional folder for committing transparent `.webm`, `.webp`, `.apng`, or `.png` graphics directly to your repo.
